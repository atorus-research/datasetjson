# datasetjson: Read and Write CDISC Dataset JSON Files

Read, construct and write CDISC (Clinical Data Interchange Standards
Consortium) Dataset JSON (JavaScript Object Notation) files, while
validating per the Dataset JSON schema file, as described in CDISC
(2023) <https://www.cdisc.org/standards/data-exchange/dataset-json>.
