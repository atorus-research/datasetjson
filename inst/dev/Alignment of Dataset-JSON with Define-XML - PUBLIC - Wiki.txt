 Alignment of Dataset-JSON with Define-XML
 Created by Lex Jansen, last updated by Lorraine Sobson on Dec 05, 2024 • 3 minute read


 Introduction
 This section provides recommendations to be followed when a Dataset-JSON v1.1 file includes reference to an associated Define-XML document; that is, when the metaDataRef top-level attribute is included. These
 recommendations are independent of the context the data is intended for. In other words, the data exchange could be for submission on any other exchange purpose. Alignment recommendations expressed in the tables in this
 section are the same for any value of the ODM/@Context attribute.
 Some recommendations may be more applicable to an operational process of transferring data from a source database directly in Dataset-JSON v1.1 format, or its NDJSON representation, rather than when converting existing SAS
 Version 5 transport files to Dataset-JSON v1.1 data exchange format.
