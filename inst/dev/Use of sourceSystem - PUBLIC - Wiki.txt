 Use of sourceSystem
 Created by Lex Jansen, last updated by Lorraine Sobson on Dec 04, 2024 • 1 minute read


 sourceSystem should be used to describe some attributes of the system where this Dataset-JSON file originated; it is an analogue of the SourceSystemName and
 SourceSystemVersion attributes from the ODM element specification. As this is intended to be system dependent it also serves as a good location for vendor
 extensions that help with semantic interoperability; an example and guidance for this are provided in Section 3, Dataset-JSON Extensions.
 In the following example of sourceSystem it is assumed:

        The sourceSystem attribute reflects the primary software used to create the source DB.
        It is possible to extend the Dataset-JSON schema to add extensions to the sourceSystem object in order to provide more detail about the system where the
        Dataset-JSON file originated.
 Example without extensions:

  {
        "sourceSystem": {
             "name": "PostgreSQL",
             "version": "16"
        }
  }
